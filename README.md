# LangChain Breakfast Assignment

A small LangChain example that asks an OpenAI chat model for five healthy breakfast ideas.

## Setup

1. Create and activate a Python virtual environment.
2. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Copy `.env.example` to `.env` and set `OPENAI_API_KEY` to your OpenAI API key.
4. Run the script:

   ```bash
   python breakfast.py
   ```

Keep `.env` and API keys out of source control.
